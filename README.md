# Harsh Raval — Portfolio Website

## Run Locally

1. Extract `harsh_raval_portfolio.zip`.
2. Open `index.html` in a modern browser.

No build tools or installation are required. The site is responsive and includes a dark/light theme toggle.

## Publish Online

You can publish this static website using GitHub Pages:

1. Upload your project files to GitHub.
2. Open repository **Settings → Pages**.
3. Select the `main` branch.
4. Select `/ (root)` and click Save.
