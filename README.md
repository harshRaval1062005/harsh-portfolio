# Harsh Raval — Portfolio Website

## Run locally
1. Extract `harsh_raval_portfolio.zip`.
2. Open `index.html` in a modern browser.

No build tools or installation are required. The site is responsive and includes a dark/light theme toggle.

## Publish online
You can publish this static site with GitHub Pages:
1. Create a repository (for example, `harshRaval1062005.github.io`).
2. Upload `index.html` and commit the changes.
3. In repository Settings → Pages, choose the deployment source/branch and save.
